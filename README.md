##Руководство пользователя

Введение
Данный документ предназначен для пользователей, работающих с игровым проектом на основе нейросетей и генетического алгоритма, реализованного в Unity. Проект представляет собой симуляцию игровой среды, где искусственный интеллект учится преодолевать препятствия путем эволюционного обучения.
Программа включает трехслойный многослойный персептрон:
Входной слой: 2 нейрона
Скрытый слой: 2 нейрона
Выходной слой: 1 нейрон
Для активации нейронов используются функции Sigmoid и ReLU.
Для работы с программой рекомендуется начальный уровень подготовки в области программирования и базовое знакомство с нейронными сетями.

Назначение и условия применения
Проект предназначен для демонстрации возможностей нейросетевого обучения в игровой среде. В частности, он подходит для следующих сценариев:
Исследования в области машинного обучения
Разработки игр с искусственным интеллектом
Образовательных целей для изучения алгоритмов эволюционного обучения
Для запуска проекта требуется:
Среда разработки Unity (версии 2020 и выше)
Поддержка C#
ОС Windows, macOS или Linux
Желательно наличие видеокарты с поддержкой аппаратного ускорения

Подготовка к работе
Установите Unity и откройте проект.
Импортируйте все необходимые зависимости, включая шрифты, аудио и графические ассеты.
Запустите сцену основного игрового процесса и убедитесь, что среда загружается без ошибок.
Проверьте корректность генерации популяций нейросетей.

Описание работы
Процесс взаимодействия с программой включает следующие этапы:
Генерация популяции агентов с различными параметрами.
Оценка их эффективности в игровой среде.
Отбор лучших агентов и создание новой популяции на основе генетического алгоритма.
Повторение итераций до достижения удовлетворительных результатов.
Аварийные ситуации и их решение
Ошибка загрузки проекта: Проверьте наличие всех файлов и зависимостей.
Сбой обучения: Убедитесь, что параметры мутации и отбора заданы корректно.
Замедление работы: Попробуйте снизить число агентов или уменьшить размер слоев нейросети.

Рекомендации по освоению
Для эффективного освоения рекомендуется:
Ознакомиться с основами нейронных сетей и генетических алгоритмов.
Провести тестовые запуски проекта и изменить параметры обучения.
Проанализировать результаты и оптимизировать архитектуру сети.
В качестве контрольного примера можно провести серию обучений с разными параметрами мутации и элитизма и сравнить эффективность агентов.
