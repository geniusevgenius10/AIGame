# Руководство пользователя

## Введение
Этот документ предназначен для пользователей, работающих с игровым проектом на основе нейросетей и генетического алгоритма, реализованного в Unity. 

Проект представляет собой симуляцию игровой среды, где искусственный интеллект учится преодолевать препятствия методом эволюционного обучения.

### Архитектура нейросети
Программа включает трехслойный многослойный персептрон:
- **Входной слой**: 2 нейрона
- **Скрытый слой**: 2 нейрона
- **Выходной слой**: 1 нейрон

Для активации нейронов используются функции **Sigmoid** и **ReLU**.

### Требования к пользователю
Для работы с программой рекомендуется начальный уровень подготовки в области программирования и базовое знакомство с нейронными сетями.

## Назначение и условия применения
Проект предназначен для демонстрации возможностей нейросетевого обучения в игровой среде. Он подходит для:
- Исследований в области машинного обучения
- Разработки игр с искусственным интеллектом
- Образовательных целей (изучение алгоритмов эволюционного обучения)

### Требования для запуска
- **Среда разработки**: Unity (версии 2020 и выше)
- **Язык программирования**: C#
- **Операционные системы**: Windows, macOS, Linux
- **Желательно**: Наличие видеокарты с поддержкой аппаратного ускорения

## Подготовка к работе
1. Установите Unity и откройте проект.
2. Импортируйте все необходимые зависимости (шрифты, аудио и графические ассеты).
3. Запустите сцену основного игрового процесса и убедитесь, что среда загружается без ошибок.
4. Проверьте корректность генерации популяций нейросетей.

## Описание работы
Взаимодействие с программой включает следующие этапы:
1. **Генерация популяции** агентов с различными параметрами.
2. **Оценка эффективности** агентов в игровой среде.
3. **Отбор лучших агентов** и создание новой популяции на основе генетического алгоритма.
4. **Повторение итераций** до достижения удовлетворительных результатов.

## Возможные ошибки и их решение
| Ошибка | Возможное решение |
|--------|------------------|
| Ошибка загрузки проекта | Проверьте наличие всех файлов и зависимостей. |
| Сбой обучения | Убедитесь, что параметры мутации и отбора заданы корректно. |
| Замедление работы | Попробуйте снизить число агентов или уменьшить размер слоев нейросети. |

## Рекомендации по освоению
Для эффективного освоения рекомендуется:
- Ознакомиться с основами **нейронных сетей** и **генетических алгоритмов**.
- Провести **тестовые запуски проекта** и изменить параметры обучения.
- **Анализировать результаты** и оптимизировать архитектуру сети.
- Провести серию обучений с разными параметрами мутации и элитизма и сравнить эффективность агентов.
